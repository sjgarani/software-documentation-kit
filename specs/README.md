# Specifications

Create dated Specs as `YYYY-MM-DD-topic.md` using the [Spec template](spec-template.md).

Follow the [Spec workflow](spec-workflow.md) for review, approval, implementation, completion, cancellation, and history updates. [ADR 0001](../adr/0001-documentation-workflow-and-agent-rules.md) defines the authoritative state transitions.
